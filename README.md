# Nythxion Shortcuts

**Nythxion Shortcuts** is a shortcut management application developed by **Nythxion Studios**.

It allows users to create and configure keyboard shortcuts for quickly launching websites and applications, providing fast access to frequently used destinations directly from Windows.

## Features

* Global keyboard shortcuts
* Website shortcuts
* Application shortcuts
* Custom shortcut configuration
* Automatic website URL normalization
* Application finder
* Application launching
* Window focusing and restoring
* Persistent shortcut configuration
* Customizable themes
* UI sound settings
* Custom Nythxion interface
* Windows desktop application
* Fast and lightweight
* Local-first operation

## Website Shortcuts

Nythxion Shortcuts allows websites to be assigned to custom keyboard shortcuts.

Website addresses are automatically normalized when necessary.

For example:

* `youtube.com` → `https://youtube.com`
* `github.com/user/repo` → `https://github.com/user/repo`
* `https://youtube.com` → unchanged
* `http://google.com` → unchanged

This allows website shortcuts to be entered without manually specifying a protocol.

## Application Shortcuts

Applications can be assigned to keyboard shortcuts and launched directly through Nythxion Shortcuts.

The application finder helps locate installed Windows applications so they can be assigned without manually entering their executable paths.

Nythxion Shortcuts can also restore or focus an existing application window when appropriate.

## Global Shortcuts

Shortcuts can be triggered globally while Nythxion Shortcuts is running in the background.

This allows frequently used applications and websites to be opened without first switching to the Nythxion Shortcuts interface.

Example shortcuts can include:

* `Ctrl + M` — Music
* `Ctrl + N` — Nythxion
* `Ctrl + D` — Discord
* `Ctrl + G` — GitHub
* `Ctrl + Y` — YouTube

Shortcuts can be changed and customized by the user.

## Settings

Nythxion Shortcuts provides settings for customizing the application.

Available settings include:

* Theme selection
* UI audio toggle

Settings are stored locally and persist between application sessions.

## User Interface

Nythxion Shortcuts uses the Nythxion Studios design system and provides a custom desktop interface.

The application includes:

* Custom Nythxion branding
* Custom popups
* Light theme
* Purple theme
* Dark theme
* Custom top bar
* Custom footer
* Smooth interface animations

The interface is designed to remain lightweight while providing a consistent Nythxion experience.

## Privacy

Nythxion Shortcuts is designed to operate locally on your computer.

Shortcut configurations and application settings are stored locally and are not automatically uploaded to Nythxion Studios.

Nythxion Shortcuts does not require administrator privileges for its normal operation.

## Performance

Nythxion Shortcuts is designed to remain lightweight while running in the background.

The application primarily performs local shortcut registration, application launching, website launching, and configuration management.

## System Requirements

### Recommended

* Windows 10 or later
* 64-bit processor
* 4 GB RAM or more
* Approximately 200 MB of available storage

## Installation

Nythxion Shortcuts is distributed through an official Windows installer.

1. Run the **Nythxion Shortcuts Setup** installer.
2. Choose the installation directory if desired.
3. Complete the installation.
4. Launch **Nythxion Shortcuts** from the created shortcut.

The installer also provides a proper Windows uninstall option.
